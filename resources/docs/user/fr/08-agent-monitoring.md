# Supervision des agents

Là où Mes utilisateurs propose un rapport *historique*, **Supervision des agents** montre ce qui se
passe **en ce moment même** (ainsi que l'historique récent de présence/statut), à travers trois
pages.

## Statut en direct

Une vue en direct du statut de chaque agent : enregistré et disponible, absent, ou indisponible (non
enregistré ou autrement injoignable). C'est la page à consulter pour savoir « qui est réellement en
ligne maintenant » avant de router un appel ou de demander à quelqu'un de rejoindre une file.

Des alertes en direct peuvent également apparaître ici — par exemple, une notification indiquant
qu'un agent est connecté depuis une durée inhabituellement longue, invitant à une vérification.

## Connexion aux files

Une carte de chaleur montrant le temps de connexion par agent **et** par file d'attente — en un
coup d'œil, quels agents passent du temps connectés à quelles files, et pendant combien de temps.
Utile pour vérifier que les effectifs correspondent réellement à l'endroit où se trouve le volume
d'appels.

## Répartition des statuts

Une répartition (barres empilées / graphiques en anneau) de la façon dont le temps de chaque agent
s'est réparti entre les statuts — Disponible, Absent, Ne pas déranger, et vos deux statuts
personnalisés (voir [Paramètres PBX → Onglet Agent](10-pbx-settings.md#onglet-agent) pour les
renommer) — par agent et par jour.

## Vues consolidées

Comme les rapports files/utilisateurs, les pages de Supervision des agents proposent une vue
« consolidée » qui agrège entre agents ou sur le groupe sélectionné, plutôt que d'afficher chaque
agent séparément.

## Pages associées

- Pour la performance historique de traitement des appels par agent (pas seulement la présence),
  voir [Mes utilisateurs](05-my-users.md).
- Pour renommer les deux statuts d'agent personnalisés affichés ici, voir
  [Paramètres PBX → Onglet Agent](10-pbx-settings.md#onglet-agent).
