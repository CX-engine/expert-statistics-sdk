# Agent Monitoring

Where My Users shows *historical* reporting, **Agent Monitoring** shows what's happening **right
now** (and recent history of presence/status), across three pages.

## Realtime Status

A live view of every agent's current status: registered and available, away, or unavailable
(unregistered or otherwise not reachable). This is the page to check "who's actually online right
now" before deciding whether to route a call or ask someone to jump on a queue.

Live alerts can appear here too — for example, a notice that an agent has been connected for an
unusually long duration, prompting a check-in.

## Queue Connection

A heatmap showing connection time by agent **and** queue — at a glance, which agents are spending
time logged into which queues, and for how long. Useful for confirming that staffing matches where
call volume actually is.

## Status Breakdown

A breakdown (stacked bar / donut charts) of how each agent's time split across statuses —
Available, Away, Do Not Disturb, and your two custom statuses (see
[PBX Settings → Agent tab](10-pbx-settings.md#agent-tab) to rename them) — per agent and per day.

## Consolidated views

Like the queue/user reports, Agent Monitoring pages offer a "consolidated" view that aggregates
across agents or across the group you've selected, rather than showing every agent separately.

## Related pages
